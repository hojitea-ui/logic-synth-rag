## 결론

- `WEAK_THRESHOLD`는 0.55로 유지한다. 근거: 막연한 정상 질문(0.56–0.59)과, 항목 이름이 들어가지 않은 자료 밖 질문(0.52–0.58)이 겹쳐 점수 하나로 가를 수 없었다. 항목 이름이 들어간 자료 밖 질문(ES2 내장 이펙트 0.703, Cutoff 0.687)은 오히려 더 높게 나왔다. 그래서 0.55를 유지했다.
- 자료에 없는 질문(ES2 내장 이펙트 0.703, Cutoff 0.687)도 ⚠ 없이 통과하므로 2단계 LLM 규칙이 필요함.

  - "Logic Pro 가격" → 단어 겹침으로 LP-007.
